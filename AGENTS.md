# ⚖️ ЮГ-ПРАВО LegalTech — Agent Rules & System Architecture

Добро пожаловать в рабочее пространство проекта **АНО «Юг-Право»**. Этот файл задает контекст, правила и стандарты для всех субагентов и автоматизаций.

---

## 🤖 1. Роли субагентов (Sub-Agents Mode)

### 🎨 Frontend Agent
- **Зона ответственности**: Верстка, компоненты интерфейса, адаптивность и клиентская валидация форм.
- **Требования**:
  - Мобильная адаптивность: тестирование на разрешениях **375px**, **390px**, **414px**, **768px**, **1280px+**.
  - **Нулевой горизонтальный скролл**: проверка `document.documentElement.scrollWidth <= window.innerWidth`.
  - Плавные анимации через **View Transitions API** и GPU-ускоренные свойства (`transform`, `opacity`).
  - Интеграция чистых inline SVG иконок через `scripts/icons.js` (Lucide Icons).
  - Интеграция с Telegram Mini App через `js/telegram-bridge.js`.

### 🛡️ QA / Reviewer Agent
- **Зона ответственности**: Аудит кода перед сохранением, валидация верстки, проверка ссылок и соответствие дизайн-системе.
- **Инструменты проверки**:
  - `npm run qa` (`node scripts/qa-audit.js`) — автоматическая проверка всех HTML файлов.
  - Проверка отсутствия битых путей к изображениям, шрифтам и локальным скриптам.
  - Проверка контрастности по WCAG AA и соблюдение дизайн-токенов (`DESIGN.md`).

## ⚖️ 2. LegalTech Data Validator (Процессуальные стандарты РФ)
При генерации или валидации процессуальных документов строго руководствоваться модулем `scripts/legal-validator.js`:
- **ГПК РФ (ст. 131, 132)**: обязательные реквизиты суда, истца (с идентификатором: СНИЛС/ИНН/паспорт), ответчика, цена иска, досудебный порядок, подтверждение отправки копий.
- **ПП РФ № 354**: споры по ЖКХ (лицевой счет, акты непредоставления услуг, перерасчет).
- **230-ФЗ**: защита прав должников (фиксация запретов на ночные звонки, превышение лимитов частоты звонков, неправомерное взаимодействие с 3-ми лицами).
- **НК РФ ст. 333.19**: актуальные ставки государственной пошлины (в ред. 259-ФЗ).

## 📄 3. Генерация процессуальных документов (PDF / DOCX)
- Генератор: `scripts/doc-generator.js`.
- Поддержка полной кириллической типографики (Times New Roman / Arial / PT Sans) без искажения кодировки.
- Соблюдение стандартов судебного делопроизводства (поля 30/10/20/20 мм, абзацный отступ 1.25 см, межстрочный интервал 1.15).

---

## 📱 4. Telegram Mini App Integration
- SDK мост: `js/telegram-bridge.js`.
- Поддержка `Telegram.WebApp.HapticFeedback` (`impactOccurred`, `notificationOccurred`).
- Синхронизация цветовой схемы через CSS-переменные (`--tg-bg-color`, `--tg-text-color`, `--tg-button-color`).
- Отправка данных через `TelegramBridge.sendToBot(data)`.

---

## 🚀 5. Локальный сервер, Port Forwarding и QR-коды
- Запуск локального сервера: `npm run dev` или `node server.js`.
- Автоматически выводится сетевой IP (`http://192.168.x.x:8080/`) и **ASCII QR-код** прямо в терминале для моментального сканирования камерой смартфона.
- Веб-страница с QR-кодом доступна по адресу: `http://localhost:8080/qr`.
